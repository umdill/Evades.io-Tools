# Installation Guide

## Google Chrome

1. Install **Tampermonkey** from the Chrome Web Store:

   * https://chromewebstore.google.com/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo
2. Open:

   ```
   chrome://extensions/?id=dhdgffkkebhmkfjojejmpbldmpobfkfo
   ```
3. Enable **Allow User Scripts**.
4. Open the userscript:

   * https://github.com/umdill/Evades.io-TAS/raw/refs/heads/main/tas.user.js
5. Click **Install** when Tampermonkey prompts you.
